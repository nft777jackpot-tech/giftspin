# GiftSpin

Telegram Mini App: казино на NFT-подарках с RTP 90%. Игры: кейсы, апгрейд, краш, рулетка, PvP-джекпот. Единственная валюта — TON, подарок при депозите пересчитывается в TON по минимальной цене коллекции.

Название рабочее, меняется в `webapp/src/config.ts`.

## Что готово

Сейчас готов только интерфейс (`webapp/`). Игры крутятся на клиенте на демо-балансе, чтобы было видно анимации. Бэкенда, бота и настоящих платежей пока нет.

Основные стили написаны вручную в `src/styles.css`. Tailwind 4 и структура shadcn (`components.json`, алиас `@/`, `src/components/ui`, `cn` в `src/lib/utils.ts`) подключены для готовых компонентов. Фон приложения — анимированный WebGL-градиент `src/components/ui/velaris.tsx`, его цвета задаются в `App.tsx`.

## Как устроен RTP

Формулы в `webapp/src/lib/rtp.ts`, RTP задаётся одной константой в `config.ts`:

- **Кейсы**: шансы подбираются так, чтобы средняя стоимость выпадения была ровно RTP × цена кейса.
- **Апгрейд**: шанс = RTP × ставка ÷ цена цели, не больше 75%.
- **Краш**: точка краша = RTP ÷ U, где U равномерно на (0, 1]. Забор на любом множителе в среднем возвращает RTP.
- **Рулетка**: 15 ячеек (7 красных, 7 чёрных, 1 зелёная), коэффициент = RTP ÷ шанс: x1.92 и x13.5.
- **PvP-джекпот**: победитель получает банк × RTP.

В рабочей версии исход будет считать сервер по схеме provably fair, а клиент только проигрывает анимацию.

## Сервер и кошелёк проекта

Папка `server/`: Node.js 24 + TypeScript (запускается без сборки), Fastify, встроенный SQLite (`node:sqlite`), `@ton/ton`. Сейчас работает в тестовой сети TON.

- **Кошелёк проекта** — горячий кошелёк v4R2. Секретная фраза лежит только в `server/.env` (права 600, в git не попадает). Создаётся командой `npm run wallet:new`, существующий кошелёк она не перезаписывает.
- **Депозит**: игрок переводит TON на адрес проекта с личным кодом `GS…` в комментарии. TON Connect подставляет код сам. Сервер раз в 10 секунд читает входящие переводы через toncenter и зачисляет их по коду. Каждый перевод зачисляется один раз. Переводы без кода и меньше минимума сохраняются для ручной проверки (`/api/admin/deposits`).
- **Вывод**: заявка сразу списывает сумму с баланса. Очередь по одной отправляет переводы с горячего кошелька с комментарием `GiftSpin #N` и ждёт подтверждения по seqno. Если перевод не ушёл, деньги возвращаются. Крупные суммы, нехватка денег на горячем кошельке и неподтверждённые переводы уходят на ручную проверку (`/api/admin/withdrawals`, одобрить или отклонить с возвратом).
- **Журнал**: любое изменение баланса — запись в `ledger`. Баланс не может уйти в минус, это проверяет сама база.
- **Вход**: в Telegram — подписанная `initData` (нужен `BOT_TOKEN`). В браузере в testnet — тестовый игрок (`DEV_AUTH=1`).
- **Админка**: заголовок `x-admin-token` с паролем из `server/.env`.
- **Лимиты** в `server/.env`: минимум депозита 0.1, вывод от 0.5 до 50 TON за раз, проверка вручную от 10 TON, 100 TON в сутки, комиссия 0.05 TON.

Пока временно: ставки и выигрыши считает сайт, а сервер им верит (`TRUST_CLIENT_GAMES=1`). Это допустимо только в testnet. Перед переходом на настоящие деньги игры нужно перенести на сервер. Сервер сам отключает этот режим в mainnet.

## Склад подарков

Сайт показывает только подарки, которые реально лежат на складе: витрина апгрейда, контрактов, ставки ботов в джекпоте и коинфлипе, лента Live. Без сервера — демо-список.

- **Склад** — отдельный Telegram-аккаунт с Premium, в нём включён Telegram для бизнеса и подключён наш бот (`WAREHOUSE=telegram`, нужен `BOT_TOKEN` с включённым Business Mode в @BotFather). Права бота: просмотр подарков и звёзд, передача и улучшение подарков, перевод звёзд. Никогда не подключайте к складу чужих ботов: так крадут подарки.
- **Сверка** раз в 5 минут (`getBusinessAccountGifts`): у каждого экземпляра статус — на витрине, у игрока, выводится, передан, пропал. Подарок, который Telegram пока не даёт передать, на витрину не попадает.
- **Цены коллекций** задаёт администратор: Telegram их не сообщает. Коллекция без цены на сайте не показывается.
- **Инвентарь** хранится на сервере. Выигрыш закрепляет за игроком конкретный экземпляр; если его успели забрать, игрок получает цену в TON. Продажа возвращает подарок на витрину и начисляет TON.
- **Депозит подарком**: игрок отправляет подарок на аккаунт-склад, бот видит его по обновлению `business_message` и зачисляет TON по цене коллекции. Подарок с маркета Telegram первые 21 день нельзя передать дальше, поэтому он зачисляется, когда это станет можно.
- **Вывод подарка** — только после проверки администратором: бот передаёт подарок (`transferGift`). Пока игры считает сайт, автоматический вывод включать нельзя. Telegram передаёт подарки только тем, кто был активен последние сутки.
- **Админка**: http://127.0.0.1:8787/admin, вход по `ADMIN_TOKEN` из `server/.env`. Там цены, сверка склада, выводы подарков и TON, депозиты, ждущие зачисления.
- **Тестовый склад**: `WAREHOUSE=fake` — 16 настоящих подарков с Fragment из `server/fixtures/stock.json`, передача только имитируется. Депозит подарком на нём можно проверить через `POST /api/admin/fake-update`.

Известное: в `@ton/ton` есть уязвимость в зависимости `zod` (исчерпание памяти на огромных ответах). Она касается только проверки ответов toncenter, а не данных от игроков. Исправления пока нет.

## Запуск

```bash
cd ~/gift-casino/server
npm install
npm run wallet:new   # один раз: создаёт кошелёк проекта и server/.env
npm run dev          # сервер на 127.0.0.1:8787
```

```bash
cd ~/gift-casino/webapp
npm install
npm run dev
```

Сайт откроется на http://localhost:5173. Запросы `/api` он передаёт серверу. Если сервер не запущен, сайт работает в демо. Проверка типов в обеих папках: `npm run typecheck`, сборка сайта: `npm run build`.

Тестовые TON выдаёт бот @testgiver_ton_bot. Кошелёк игрока для проверки — тестовый аккаунт Tonkeeper. В Tonkeeper нет переключателя сети: тестовый аккаунт заводится из 24 слов обычного кошелька. Создайте отдельный пустой кошелёк, сохраните его 24 слова, затем «Добавить кошелёк» → «Testnet Account» (или Настройки → 5 раз нажать на логотип → Dev Menu → Import Testnet Wallet) и введите эти слова. Перед подключением к сайту выберите в Tonkeeper этот тестовый аккаунт: кошелёк из основной сети сайт не подключит.

## Публикация

Сайт опубликован на GitHub Pages: https://nft777jackpot-tech.github.io/giftspin/ (репозиторий `nft777jackpot-tech/giftspin`, открытый).

- Каждый push в `main` сам собирает и публикует сайт (`.github/workflows/pages.yml`).
- На Pages нет сервера, поэтому сайт собирается с пустым `VITE_API_URL` и работает в демо: демо-баланс, демо-витрина, без настоящих депозитов. Когда сервер будет на своём хостинге с HTTPS, его адрес задаётся в `VITE_API_URL`, например `https://api.example.com/api`.
- Пути относительные (`base: './'`), поэтому сайт работает и из папки `/giftspin/`, и в корне своего домена.
- Правила GitHub Pages запрещают использовать его для онлайн-бизнеса и коммерческих операций. Для демо подойдёт, но настоящее казино нужно переносить на свой хостинг, иначе GitHub может заблокировать сайт или аккаунт.

## Дальше

1. **Игры на сервере** (начато): сервер сам принимает ставку, считает исход честной схемой и меняет баланс — клиент его не подделает. Готов **дайс** (`server/src/games.ts`, `fair.ts`, `SERVER_GAMES`, эндпоинты `/api/games/dice`, `/api/fair`). Дальше по тому же образцу: мины, плинко, лимбо, рулетка, кейсы, апгрейд, контракты; затем PvP (коинфлип, джекпот, батлы) и реальный онлайн — через WebSocket. После переноса всех игр — отключить `TRUST_CLIENT_GAMES`. **Важно:** PvP и онлайн заработают на опубликованном сайте только с собственным хостингом сервера (HTTPS + WebSocket); на GitHub Pages сервера нет, там сайт всегда в демо.
2. **Бот**: кнопка запуска Mini App, приветствие в чате склада со ссылкой на Mini App и подсказкой, как пополнить подарком (так делает Gift Relayer у Virus Gift), уведомления о выигрышах и выводах.
3. **Бонусы с отыгрышем**: награды за задания и промокоды приходят в TON, поэтому перед запуском на настоящие деньги их нужно закрыть отыгрышем, иначе их будут фармить мультиаккаунтами.
4. **Оценка подарков**: подтягивать минимальные цены коллекций с маркетплейсов по расписанию вместо ручных цен в админке.
5. **Админка**: оборот и банк, переводы без кода, лимиты — к уже готовым ценам, складу и выводам.
6. **Деплой**: VPS с HTTPS-доменом (Telegram открывает Mini App только по HTTPS), свой `tonconnect-manifest.json`, ссылка на Mini App в BotFather, PostgreSQL вместо SQLite, отдельный холодный кошелёк для запаса.
